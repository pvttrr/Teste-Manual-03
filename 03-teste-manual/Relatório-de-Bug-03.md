#  Relatório de Bug - 03

# Erro de carregamento ao tentar agendar entrevista já agendada antes


## Descrição :
Ao acessar o perfil de um candidato no módulo de Recrutamento e tentar clicar no botão de agendamento de entrevista (que já foi agendada), acontece um erro de carregamento

## Passos para Reproduzir :
1° - Acessar o módulo “Recruitment”
2° - Abrir o perfil de um dos candidatos cadastrados
3° - Identificar uma entrevista que já foi agendada
4° - Clicar no botão para reagendar ou visualizar detalhes da entrevista
5° - Observar a falha de carregamento

## Resultado Esperado :
O sistema deve carregar as informações da entrevista agendada

## Resultado Atual : 
O botão não responde e/ou gera erro de carregamento, impedindo a ação

Alta

Alta

Aberto
