#  Relatório de Bug - 02

# Não é possível aplicar a licença de férias 


## Descrição :
Ao tentar aplicar uma licença no módulo de férias , não tem nenhuma opção de licença sendo exibida, dificultando a solicitação

## Passos para Reproduzir :
1° - Acessar o menu "Leave"
2° - Clicar em "Apply "
3° - Conferir se aparecem os tipos de licença disponíveis

## Resultado Esperado :
Deve ser exibido  uma lista de tipos de licença disponíveis

## Resultado Atual : 
A mensagem "No Leave Types with Leave Balance" é exibida e nada aparece

## Severidade :
Alta

##  Prioridade :
Alta

##  Status :
Aberto
