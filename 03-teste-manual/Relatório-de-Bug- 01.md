#  Relatório de Bug - 01

# Não há mensagem explícita de sucesso no ato de login


## Descrição :
O sistema não exibe mensagens de sucesso de forma clara após login, apenas redireciona ou atualiza a página.

## Passos para Reproduzir :
1° - Acessar a página de login
2° - Inserir credenciais válidas
3° - Clicar em "Login"

## Resultado Esperado :
Mensagem como "Login realizado com sucesso" deve ser exibida na tela

## Resultado Atual : 
Usuário é redirecionado diretamente sem nenhuma mensagem 

## Severidade :
Média 

##  Prioridade :
Média

##  Status :
Aberto
